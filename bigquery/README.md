# CareFlow - BigQuery Warehouse Setup

## Week 1 - Data Foundation

### Role
Member 2 - BigQuery Warehouse Setup

## Objective

The objective of this task is to create the BigQuery data warehouse layer for the CareFlow Clinical Pathway Process Mining project.

The raw EHR event log generated by Member 1 is uploaded to Google BigQuery and stored in a structured table. The data is validated using SQL queries before being passed to the dbt transformation stage.

## BigQuery Structure

Google Cloud Project  
└── careflow_raw  
    └── ehr_event_log_raw

### Dataset

`careflow_raw`

### Raw Table

`ehr_event_log_raw`

## Table Schema

| Column | Data Type | Description |
|---|---|---|
| Case_ID | STRING | Unique identifier for a patient journey |
| Activity_Name | STRING | Hospital activity performed during the patient journey |
| Timestamp | TIMESTAMP | Date and time when the activity occurred |

## Data Source

The raw event log was provided as a CSV file generated by Member 1.

`careflow_event_log_clean.csv`

The event log contains timestamped healthcare activities representing patient journeys through the hospital.

Example process:

Registration → Triage → X-Ray → Doctor → Discharge

The dataset also contains repeated activities and loop-backs. These are intentionally preserved because they represent operational inefficiencies that will later be discovered using process mining.

Example:

Triage → X-Ray → Triage → X-Ray
