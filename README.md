CareFlow – Clinical Pathway Process Mining

🏥 Project Overview

CareFlow is a healthcare operations and process analytics project designed to identify hidden bottlenecks in hospital patient workflows, particularly Emergency Room (ER) wait times.

Traditional BI dashboards show metrics such as average waiting time, but they often fail to explain why delays occur. CareFlow uses Process Mining to reconstruct the actual sequence of events experienced by patients from timestamped Electronic Health Record (EHR) event logs.

The system generates a visual process map of patient journeys and identifies repeated activities, delays, loop-backs, and inefficient pathways.
