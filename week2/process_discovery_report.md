# CareFlow Clinical Pathway Process Mining

## Week 2 – Member 3: Process Discovery & Pathway Mining

### 1. Objective

The objective of this task is to perform process discovery and pathway analysis on the standardized clinical event log using PM4Py.

The analysis uses the normalized event log containing:

- Case ID
- Activity Name
- Event Timestamp

### 2. Dataset

The final normalized event log was obtained from the BigQuery `event_log` view in:

- Project: `aerial-episode-509608-t7`
- Dataset: `careflow_analytics`
- View: `event_log`

The event log was exported to CSV and processed locally using Python and PM4Py.

### 3. Tools and Technologies

- Python
- Pandas
- PM4Py
- Graphviz
- BigQuery
- GitHub

### 4. Data Preparation

The following preprocessing steps were performed:

1. Loaded the normalized event log.
2. Verified required columns.
3. Checked for missing values.
4. Converted timestamps to datetime format.
5. Sorted events by Case ID and Event Timestamp.
6. Formatted the data for PM4Py.

### 5. Process Discovery

The following process mining techniques were applied:

#### Directly-Follows Graph (DFG)

The DFG represents the transitions between consecutive clinical activities and their frequencies.

Output:

`outputs/dfg.png`

#### Petri Net

The Alpha Miner algorithm was used to discover a Petri Net representing the clinical process flow.

Output:

`outputs/petri_net.png`

#### Heuristics Miner

The Heuristics Miner was used to identify the main process behavior while considering activity frequencies.

Output:

`outputs/heuristics_net.png`

### 6. Pathway Analysis

Patient pathways were generated by grouping activities according to Case ID and ordering them by timestamp.

The top 10 most frequent pathways were saved in:

`outputs/top_pathways.txt`

### 7. Loop-Back Analysis

Repeated activities within patient cases were analyzed to identify loop-back behavior in the clinical pathway.

Output:

`outputs/loopback_analysis.txt`

### 9. Process Summary

A consolidated process summary containing the main process statistics, start activities, end activities, and activity information was generated.

Output:

### 10. Conclusion

PM4Py was successfully used to discover and analyze the clinical pathway from the standardized event log. The analysis provides process-flow visualization, patient pathway patterns, activity frequencies, case durations, and loop-back behavior.

These outputs can be used as inputs for subsequent clinical pathway analysis and dashboard reporting.
